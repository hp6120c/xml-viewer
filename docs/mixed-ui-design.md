# XML / Markdown 混合工作区界面设计

## 核心原则

采用“共用外壳 + 类型化工作区”，而不是为 XML 和 Markdown 做两套独立窗口。

- 顶部品牌、打开文件、打开文件夹、刷新、缩放、更新和默认应用设置保持固定。
- 文件标签页是唯一的多文件入口，标签上同时显示文件类型和文件名。
- 切换标签只替换工作区内容，不重建整个应用。
- XML 和 Markdown 各自保留自己的视图状态，不互相覆盖。

## 层级结构

```text
品牌与版本
全局工具栏
文件标签页
当前文件上下文工具栏
当前文件统计栏
左侧导航 / 大纲 + 右侧工作区
底部状态栏
```

## 文件标签页

标签页使用“图标 + 文件名 + 类型标签”：

```text
[数据库图标] scl_schema.xml  [XML]  ×
[文档图标]   README.md       [MD]   ×
[文档图标]   接口设计说明.md [MD]   ×
```

- XML 使用蓝色类型标签，Markdown 使用绿色类型标签。
- 颜色只作为辅助，不能只依赖颜色区分类型。
- 有未保存内容时在文件名后显示圆点。
- 关闭标签时若存在未保存修改，弹出保存 / 放弃 / 取消。
- 标签页右键菜单提供关闭、关闭其他、关闭全部、刷新、复制路径、打开所在文件夹。

## 上下文工具栏

全局操作固定在顶部；当前文件相关的操作放在标签页下方的上下文栏。

### XML 激活时

```text
[XML 数据库] 搜索表名、字段名或备注      全部表目录  编辑当前表
```

统计栏显示：

```text
模块 2  表 3  字段 12                      当前：scl_schema.xml · 8.0 KB
```

工作区保持现有结构：

```text
数据表导航 | 表目录 / 表详情
```

### Markdown 激活时

```text
[Markdown 文档]  阅读 / 编辑  在当前文档中查找  大纲  舒适宽度
```

统计栏显示：

```text
标题 8  字数 3,245  预计阅读 12 分钟       当前：README.md · 12.6 KB
```

工作区采用：

```text
文档大纲 | 渲染后的文档
```

编辑模式下可切换为源码与预览双栏；阅读模式只显示渲染结果。

## 混合打开示例

先打开 `scl_schema.xml`，再打开 `README.md`：

1. 两个文件都出现在顶部标签栏。
2. 当前激活的标签决定下方工作区类型。
3. 从 XML 切到 Markdown 时，未保存的 XML 编辑内容仍保留。
4. 从 Markdown 切回 XML 时，原表选择、目录展开状态和滚动位置恢复。
5. 两个文件各自拥有自己的搜索关键词、视图模式和未保存状态。

默认只显示一个活动工作区，不同时把 XML 表格和 Markdown 文档塞进同一屏，避免信息密度过高。后续如需对照阅读，可以在独立功能中增加“左右分屏”。

## 目录和文件树

打开包含多种文件的目录时，不建议一次性把大量文件全部打开成标签页。推荐在左侧增加可切换的 `文件` 面板：

- XML 文件显示数据库图标。
- Markdown 文件显示文档图标。
- 点击文件后打开或激活标签页。
- XML 的 `结构` 面板和 Markdown 的 `大纲` 面板保持各自独立。

## 默认应用设置

工具栏按钮命名为“默认应用设置”，点击后打开 Windows 默认应用页面。程序不能静默把 XML 和 Markdown 同时设为默认应用；安装包只负责注册候选应用，最终由用户在 Windows 中确认。

## 视觉约束

- 不改变现有 XML 表格的主体布局，只增加类型标识和上下文工具栏。
- Markdown 文档在工作区内铺满可用面板，正文使用可切换的舒适阅读宽度。
- 代码块、表格、图片等宽内容不允许撑破整个页面。
- 窄窗口下隐藏左侧导航/大纲，保留文件标签和当前文档操作。
- 文件类型、当前模式和未保存状态必须有文字或图标提示。
